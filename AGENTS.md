# StoryForge Agent Guide

StoryForge is a .NET 10 desktop application for fiction planning. The current code is authoritative when it differs from documentation.

Start with [docs/INSTRUCTIONS.md](docs/INSTRUCTIONS.md), then read the document relevant to your change:

- [Architecture](docs/ARCHITECTURE.md) — projects, dependency boundaries, startup, and DI.
- [Operations](docs/OPERATIONS.md) — Keystone dispatch, results, handlers, and project scopes.
- [Domain and Persistence](docs/DOMAIN-PERSISTENCE.md) — entities, IDs, repositories, and EF Core.
- [UI](docs/UI.md) — the active BlazorBlueprint presentation layer and page conventions.
- [Conventions](docs/CONVENTIONS.md) — naming, async, errors, and logging.
- [Verification](docs/VERIFICATION.md) — build, test, and safety checks.
